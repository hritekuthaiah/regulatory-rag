# Regulatory & Compliance Document Assistant

A retrieval-augmented question-answering system over SEBI circulars. It answers compliance questions with cited source passages (circular number + clause), refuses when the retrieved evidence is too weak to support an answer, and tracks retrieval quality against a labelled evaluation set. Built from scratch in Python (no LangChain/LlamaIndex), served with FastAPI, and deployed on AWS free tier.
